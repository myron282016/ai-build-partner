# AI Build Partner landing page

Deploy-ready static site.

## Files
- `index.html` — complete landing page (styles + interactions embedded)
- `myron.jpg` — founder photo

## Before launch
1. Replace `https://calendly.com/YOUR-USERNAME/15min` in `index.html` with your real Calendly event URL.
2. Configure the Calendly event as a 15-minute consultation and add these three required questions:
   - What type of business do you run?
   - What would you like help with? (app/product idea, automate something, business problem/not sure what to build, learn to build with AI, other)
   - Briefly, what would you like to accomplish?
3. Review the public bio and pricing before publishing.

## Deploy
Upload `index.html` and `myron.jpg` to a GitHub repository and import the repository into Vercel as a static site.
